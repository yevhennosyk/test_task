close-up detection rate for flying drone is ~70% and it is detected as an airplane.
close-up detection rate for turned off drone is ~50% and it is detected as many things (such as a person, a bench, a motorcycle, a bicycle).
close-up detection rate for drone in the hand of the person is ~10% and it is detected as many things (such as a person, a motorcycle, a bicycle).
with increased distance the detection rate is ~0%.
